Put cut-out photos of yourself here for YouTube thumbnails (transparent background PNG).
Name each file after the expression, for example:
  shocked.png  serious.png  pointing.png  smiling.png  thinking.png  arms-crossed.png
Tips: chest-up framing, strong expression, good light, high resolution (1000px+ tall).
Easy ways to get a transparent PNG: iPhone (touch and hold the subject in Photos > Copy / Share),
remove.bg, Canva "BG Remover", or install `pip install rembg` and drop in normal photos.
